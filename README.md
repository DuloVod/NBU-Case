# NBU University Challenge 2026 — команда УКУ

Спільна база даних, досліджень і моделей для підготовки монетарних рекомендацій Правлінню НБУ. [Перевірені умови, кінцеві цілі та незавершені результати](docs/project/COMPETITION_BRIEF_UA.md). Поточний інформаційний зріз моделей — **22 жовтня 2026 року**: завершені місячні макродані до вересня та відомі ставки за 1–22 жовтня.

**Поточний горизонт дослідження — три місяці: листопад 2026, грудень 2026 і січень 2027.** Прогнозуємо середню облікову ставку за календарні дні кожного місяця. Короткострокова рекомендація супроводжується аналізом інструментів, валютних умов і ризиків. Далекі траєкторії вилучені з основного звіту.

Починайте з [поглибленого дослідження рішення](reports/2026-10-22-research/RESEARCH_UA.md), [доказового датасету](data/research/2026-10-22/README.md) та [протоколу спільної роботи агентів](docs/methodology/AGENT_RESEARCH_PROTOCOL_UA.md).

**Тримісячний запуск:** ARIMA, SARIMA, VAR, QPM + міст, незмінна ставка та прозорий ансамбль із вагами окремо для кожного горизонту. Ансамбль: **16,015 / 16,036 / 16,014%**; відібраний за validation орієнтир — **16 / 16 / 16%**. В ансамблі 4 моделі плюс стабілізатор, а не 12 складових. [Прогнози](results/2026-10-22-short-term/forecast.csv), [точні ваги](results/2026-10-22-short-term/ensemble_weights.csv), [історична перевірка](results/2026-10-22-short-term/metrics.csv).

## Запуск

Потрібен Python 3.12. З кореня репозиторію:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python tools/run_research.py
python tools/verify_short_term.py
python -m unittest discover -s tests -v
```

Поточний запуск працює офлайн. Використовує перевірений кеш історичних прогнозів або заново оцінює моделі з `python tools/run_research.py --refresh`. Відтворює ваги, відбір, аудит і три місяці графіків; при зміні джерел кеш відхиляється. Розширений архів запускається тільки явно: `--include-medium-term`. [Методика](docs/methodology/SHORT_TERM_UA.md). Для окремого відтворення попереднього одномісячного чотиримодельного порівняння:

```sh
python models/run_monthly.py
python models/make_monthly_report.py
```

У Windows активуйте середовище через `.venv\Scripts\Activate.ps1`; надалі використовуйте `python`.

Кожна модель запускається окремо:

```sh
python models/monthly_qpm.py
python models/monthly_arima.py
python models/monthly_sarima.py
python models/monthly_var.py
```

Історичний прогноз без перезапису основних результатів:

```sh
python models/monthly_qpm.py --as-of 2023-11-22 --output results/local/example_2023_11
```

Повна перевірка відтворення даних з оригіналів, без зміни робочої бази:

```sh
python tools/rebuild_data.py --check
```

Звичайний запуск моделей використовує вже підготовлені дані й не потребує доступу до сайтів НБУ. Числове відтворення не оновлює оформлений XLSX автоматично; [подробиці](docs/methodology/REPRODUCTION_UA.md).

## Початкове чотиримодельне порівняння: листопад 2026

Прогноз **середньої ставки за листопад**: QPM + місячний міст **15,64%**, ARIMA **16,06%**, SARIMA **15,97%**, VAR **16,32%**. Орієнтир незмінної чинної ставки — **16,00%**.

На 92 однакових місячних зрізах орієнтир незмінної ставки має **MAE 0,459 в. п. та RMSE 1,626 в. п.** і перевершує всі чотири моделі за обома метриками. Тому цей запуск не дає сильного кількісного обґрунтування відхилення листопадового прогнозу від рівня близько 16%.

**QPM + місячний міст не є новою оціненою місячною структурною QPM.** Її квартальні коефіцієнти походять із шаблону; відомі місячні ставки застосовані через явний стохастичний міст. Жовтень має статус nowcast, листопад — forecast. Майбутні дні не оголошені фактами.

Зберігаються поточні історичні перегляди, наближений календар макропублікацій та умовні Gaussian-інтервали. Це псевдопозавибіркова перевірка, не повний тест на архівних вінтажах. [Архівний квартальний звіт](reports/2026-10-21/REPORT_UA.md) збережено; `models/run_all.py` запускає саме архівну квартальну задачу.
