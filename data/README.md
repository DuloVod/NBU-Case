# Датасет для власної QPM команди УКУ

Версія: 21 жовтня 2026. Останній місяць: вересень 2026, якщо показник уже опублікований.

## З чого почати

1. Відкрийте **QPM_ready.xlsx**. Кожен показник стоїть в окремому стовпці, кожне число — в окремій числовій комірці. Жодного імпорту CSV для перегляду не потрібно.
2. Аркуш **Повна вибірка** — 66 повних кварталів, 2010Q1–2026Q2. Колонки: `l_gdp`, `l_cpi`, `ir_pol`, `l_er`, `l_gdp_ea`, `l_cpi_ea`, `ir_ea`.
3. Для коду використовуйте **model/quarterly_training.csv**: ті самі 66 кварталів і 7 показників. Логарифми вже помножені на 100, ставки вже у % річних.
4. Для роботи в рівнях — **model/quarterly_balanced.csv**. Для останнього неповного кварталу — **model/quarterly_observations.csv** або **quarterly_levels.csv**.
5. Додаткові показники — **auxiliary_monthly.csv**, **auxiliary_quarterly.csv**, **quarterly_extended.csv**. Вони мають різне покриття і пропуски; автоматично скорочувати за ними основну вибірку не потрібно.

## Формати файлів

- **QPM_ready.xlsx** — основний файл для людей. Справжній Excel із окремими комірками та числовими типами.
- **model/*.csv** — файли для моделювання: розділювач кома, десяткова крапка, UTF-8. Подвійне клацання в Excel із регіональним розділювачем «;» може показати один стовпець; це не формат Excel-книги.
- **csv_for_excel/*.csv** — додатковий варіант із розділювачем «;», десятковою комою та UTF-8 BOM. Якщо налаштування Excel інші, відкривайте XLSX або виконуйте імпорт із явним вибором розділювача.
- **raw/** — незмінені первинні завантаження, включаючи оригінальні XLS/XLSX. Їхні авторські змістові аркуші можуть мати один заповнений стовпець; це не злитий датасет.
- **inputs/** — попередня перевірена база та трасування основних змінних, необхідні для відтворення.
- **documentation/** — методика, джерела, словник, покриття, перевірки, компоненти сезонності та аудит кожного аркуша первинних Excel.
- **reproduce/** — відтворення числових файлів. Excel є збереженим знімком, зміна комірки не перебудовує CSV.

Порожня комірка означає відсутні дані. Нуль є реальним числом. Прогнози НБУ, опитування й зовнішні припущення зберігаються окремо від фактів.

Це підготовка даних для власної QPM. Потенційний ВВП, нейтральні ставки, рівноважний курс, параметри та дисперсії шоків повинна оцінювати ваша модель.
