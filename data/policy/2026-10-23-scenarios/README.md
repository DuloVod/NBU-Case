# Первинні докази для зимових умовних сценаріїв

Основний cutoff: кінець дня **22.10.2026**. Нові скачування: **23.10.2026**, точні UTC-часи в `sources_manifest.json`. Дата отримання не є датою публікації. Текст навігації після cutoff у повному HTML не використовується як економічний доказ.

- `raw/`: Нафтогаз22Oct, IEA2025/Feb2026, закон3878-IX, коментар НБУ12Oct; зображення BOS p.56/p.59 — візуальна перевірка старого PDF.
- `sources_manifest.json`: URL, publication/adoption окремо, час отримання, HTTP-status, SHA-256. ДПС прямий download403 зафіксований, цифри офлайн походять з Верховної Ради. П'ять старих джерел використовуються read-only за їхнім первинним шляхом.
- `shock_evidence.csv`: 31 рядок статистики, опитувань і законодавчо встановлених податкових ставок. Майбутня ставка податку має окремий статус; це не фактична майбутня роздрібна ціна. Структурних коефіцієнтів/імовірностей тут немає.
- `shock_evidence_excel.csv`: окремий CSV UTF-8 BOM, «;», десяткова кома, для українського Excel. За потреби імпорт через «Дані → З тексту/CSV» з роздільником «;».
- `extraction_checks.json`: кількість рядків, використані джерела, derived-image хеші, знакова примітка пального.

Відтворити вибірку **без мережі**, зі збережених джерел і pypdf:

```sh
python data/policy/2026-10-23-scenarios/extract_evidence.py
```

Manifest існуючих файлів можна перебудувати без скачування:

```sh
python data/policy/2026-10-23-scenarios/collect_sources.py
```

Завантаження виконується тільки з явним `--download`, пропускає вже збережені файли. Воно не є частиною офлайнової репродукції. Збережена Нафтогаз-публікація від22Oct13:38 допустима за cutoff кінець дня; для intraday cutoff12:22 вона недопустима.
