# Відтворення

Потрібні Python 3.12 та бібліотеки кореневого `requirements.txt` репозиторію.

Безпечна перевірка з кореня репозиторію, без перезапису робочої бази:

`python tools/rebuild_data.py --check`

Для окремої нової копії: `python tools/rebuild_data.py --output /absolute/path/to/new-dataset`.

Прямий перерахунок уже вилучених даних із кореня репозиторію:

`python data/reproduce/calibrate.py --root data`

Команда читає незмінені raw/ та inputs/, перебудовує model/ і числову документацію. Файли CSV для людей зберігаються з «;» і десятковою комою, для моделей — з «,» і десятковою крапкою. Оформлений XLSX є статичним знімком і цією командою не оновлюється.

Повне повторне вилучення основної бази з 15 оригіналів: `python reproduce/audit_inputs.py`, `python reproduce/prepare_dataset.py`. Ці дві старі команди створюють data/ та documentation/ первинного формату. Після цього скопіюйте числові CSV з data/ у inputs/ і запустіть calibrate.py. Архів рішень НБУ вже збережений у raw/, мережеві оновлення не потрібні.

Майбутні траєкторії не генеруються автоматично. Читання книги моделі та оцінювання її коефіцієнтів не виконуються.
