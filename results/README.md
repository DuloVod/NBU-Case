# Поточні числові результати

Активний запуск для реакції на шок — [2026-10-22-policy-decision](2026-10-22-policy-decision/RUN_SUMMARY_UA.md).

- `calibration/` — критерій відбору без ставки, сітка параметрів і прогнозні перевірки.
- `nowcast/` — місячна інфляція: ARIMA, SARIMA, VAR, VAR з валютним тиском; validation/audit з embargo.
- `decision/` — однакові шоки для різних ставок, траєкторії, втрати, чутливість до gap/коефіцієнтів та числова перевірка рівнянь.
- `history/` — чотири історичні епізоди; ex-post порівняння не доводить причинного успіху фактичної політики.
- `run_manifest.json`, `verification.json` — контрольні суми і незалежна перевірка запуску.

Попередній допоміжний прогноз поведінки ставки — [2026-10-22-short-term](2026-10-22-short-term/).

- `forecast.csv` — 18 прогнозів: шість кандидатів на три місяці.
- `ensemble_weights.csv` — ефективні ваги п'яти компонентів за місяцями.
- `metrics.csv` — MAE, RMSE та покриття інтервалів за горизонтом і перевірочним періодом.
- `backtest.csv` — усі 1 638 завершених історичних прогнозів.
- `calendar_scenarios.csv` — механічні сценарії місячних середніх.
- `protocol.json`, `summary.json` — правила відбору та підсумок.
- `base_forecast_cache.csv`, `base_model_metadata.json` — кеш оцінювання й діагностика, потрібні для відтворення та аудиту.
- `base_cache_manifest.json`, `run_manifest.json` — контрольні суми входів/виходів і версії середовища.

Великі технічні файли тут не є сміттям: вони дозволяють перевірити, звідки взялися підсумкові цифри. Для презентації користуйтеся [графіками](../reports/final/RESEARCH_UA.md).
