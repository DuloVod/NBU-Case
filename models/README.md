# Навігація моделями

Основний запуск після вимоги про реакцію на шок: `python tools/run_policy_research.py`. Числові результати — `results/2026-10-22-policy-decision/`; PDF не генерується.

- `policy_qpm.py` — точні інфляційні цілі, однобічний фільтр, шумне експертне судження, пряме задання ставки з ендогенним шоком правила.
- `policy_calibration.py` — 9 прогнозних калібрувань; ставка не входить до критерію відбору, історичне експертне судження вимкнено.
- `policy_nowcast.py` — ARIMA/SARIMA/VAR та VAR з інтервенціями для headline CPI; це прогнози інфляції, не оптимізатори ставки.
- `policy_decision.py` — незмінний шок для всіх альтернатив ставки, календарний міст, функції втрат і чутливість.
- `policy_history.py` — прогнозні помилки та явно ретроспективні умовні порівняння чотирьох історичних епізодів.

Попередній прогноз фактичної ставки: `python tools/run_research.py`.

- `research_short_term.py` — три місяці, ансамбль, відбір, історична перевірка.
- `make_short_term_report.py` — єдиний актуальний звіт у `reports/final/`.
- `monthly_arima.py`, `monthly_sarima.py`, `monthly_var.py`, `monthly_qpm.py` — чотири прогнозні моделі.
- `monthly_common.py`, `common.py` — дані, дати, перетворення та спільні функції.
- `arima.py`, `sarima.py`, `var.py`, `qpm.py` — базові реалізації, потрібні місячним моделям і тестам.
- `research_monthly.py`, `research_qpm.py`, `run_all.py`, `run_monthly.py` — допоміжні функції й попередні експерименти, частково потрібні поточному запуску та регресійним тестам. Це не основні команди. Старі експериментальні запуски можуть вимагати попередніх артефактів з історії Git.

Застарілі генератори квартального, одномісячного та довгого звітів видалені з поточної версії. Математику моделей під час упорядкування не змінювали.
