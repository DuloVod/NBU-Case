# Висновки та результати

## Поглиблене дослідження рішення

[Консолідований звіт 22.10.2026](../../reports/2026-10-22-research/RESEARCH_UA.md), [усі розрахунки](../../results/2026-10-22-research/), [нові докази](../../data/research/2026-10-22/README.md).

12 місячних кандидатів і хронологічний аудит дають відібраний прогноз середньої листопада **16%**. Структурні сценарії та нові інфляційні/валютні дані дають аргументи для робочої рекомендації **16,5%**, основна альтернатива — 16%. Це різні результати; команда ще не затвердила фінальне рішення. Перевірено 109 калібрувань QPM, чутливість до припущень і ваг втрат. Статистично доведеної оптимальної ставки не встановлено.

## Висновки архівного квартального порівняння

QPM має найменшу загальну RMSE на перевірених горизонтах, але не перемагає кожен орієнтир за кожним критерієм. На один квартал незмінна ставка має кращу MAE. Сезонне ускладнення ARIMA не дало переваги. VAR корисна як додаткова перевірка, але в цьому тесті не має підстав бути основною прогнозною моделлю.

Сильна слабкість QPM — занадто вузькі модельні інтервали. Успішний розв'язок рівнянь не є доказом достатньої емпіричної точності або правильної оцінки ризику.

Ці результати не доводять оптимальності конкретної майбутньої ставки. Для рекомендації НБУ ще потрібні сценарії, оцінка ризиків і погоджені зовнішні припущення.
