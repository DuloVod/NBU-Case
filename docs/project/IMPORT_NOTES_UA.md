# Перенесення матеріалів у спільний репозиторій

Дата: 21.10.2026. За основу взято поточний `main` після перевірки віддалених гілок і двох наявних комітів. Попередні файли партнера залишені без зміни вмісту та розташування.

## Додано

- Повний унікальний знімок підготовленого датасету: оригінали, основні й допоміжні ряди, Excel, джерела, словник, покриття, протоколи перевірок і код відтворення.
- Чотири Python-моделі, спільна обробка, історичне порівняння та генератор звіту.
- Усі збережені прогнози й висновки поточного запуску, окремі режими та діагностика невизначеності.
- Контекст дослідження, джерельний звіт, методика, робочі теоретичні нотатки й список навчальних матеріалів.
- Інструкція запуску, правила співпраці та GitHub Actions для перевірок.

## Як усунено дублікати

Попередній пакет моделей містив власну копію всього датасету. У репозиторії є одна спільна папка `data/`; усі моделі читають її.
Початковий NBU-шаблон не дублюється: QPM читає `nbu_challenge_model_2026/model/`, який уже додав партнер.
ZIP-архіви, бібліотеки Python/Node, кеші, проміжні витяги та знімки екрана не потрібні для цієї структури й не додані.
Навчальні розділи сторонніх підручників, передані як контекст, перелічені в бібліографії, без копіювання PDF у публічний репозиторій.

## Перевірено локально

- Усі чотири моделі запущено зі структури репозиторію; 356 історичних прогнозів відтворено.
- Дев'ять тестів моделей і цілісності даних пройшли.
- Числову базу заново отримано з оригіналів у тимчасовій папці: усі 18 модельних CSV збігаються з поточною базою в межах зафіксованого числового допуску.
- Перевірено доступність зафіксованих залежностей через pip resolver.
- Статистичні оригінали й готовий XLSX скопійовано без зміни вмісту.

Зміни в Python порівняно зі старим окремим пакетом стосуються насамперед шляхів, спільної структури й запису метаданих. Економічні рівняння та специфікації прогнозування не змінювалися під час цього перенесення.
