# Історія та прибирання репозиторію

До впорядкування повний стан збережений у коміті **388c3d3f9569442428b2bbd094608a66f2886631**.

[Відкрити попередню версію](https://github.com/DuloVod/NBU-Case/tree/388c3d3f9569442428b2bbd094608a66f2886631).

Із поточної версії прибрані попередні звіти й розрахунки:

- `reports/2026-10-21/`, `results/2026-10-21/` — квартальна задача.
- `reports/2026-10-22-monthly/`, `results/2026-10-22-monthly/` — перший прогноз листопада.
- `reports/2026-10-22-medium-term/`, `results/2026-10-22-research/` — розширені експерименти й довгі сценарії.
- Генератори цих звітів та старий окремий аудитор розширеного дослідження.

Поточний тримісячний звіт перенесено з `reports/2026-10-22-research/` до `reports/final/`. Посилання, генератор звіту та незалежну перевірку оновлено. Математика моделей, вхідні дані та прогнози не змінені.

Первинні дані, оригінальний шаблон і початкові файли партнера збережені. Технічні кеші й діагностика поточного запуску збережені для відтворення. Старі матеріали можна переглянути або відновити з наведеного коміту без зміни поточного робочого стану.
