# Відтворення поточного дослідження

Із кореня репозиторію після встановлення `requirements.txt`:

```sh
python tools/run_research.py
python tools/verify_short_term.py
python -m unittest discover -s tests -v
```

Звіт — `reports/final/`, числа — `results/2026-10-22-short-term/`. Для повного повторного оцінювання використовуйте `python tools/run_research.py --refresh`. Без цього використовується перевірений кеш із відповідними SHA256. Інформаційна дата не оновлюється автоматично. [Методика](SHORT_TERM_UA.md).

Попередні запуски перенесено до [історії Git](../project/HISTORY_UA.md); вони не є частиною поточного комплекту.

## Дані

`data/reproduce/` містить три етапи:

1. `audit_inputs.py`: відкриття первинних 15 файлів і вилучення клітинок/тексту.
2. `prepare_dataset.py`: вилучення основних рядів і формування початкових CSV.
3. `calibrate.py`: остаточна узгоджена база, сезонність, додаткові ряди, документація та перевірки.

Зручна безпечна перевірка:

```sh
python tools/rebuild_data.py --check
```

Вона створює тимчасову копію, виконує всі три етапи, порівнює 18 модельних CSV з робочою базою й не змінює `data/`.

Для окремої експериментальної копії:

```sh
python tools/rebuild_data.py --output /absolute/path/to/new-dataset
```

Папка призначення повинна бути новою. Оригінали не перезаписуються. Інтернет не потрібний: усі вибрані оригінали та архів рішень уже збережені.

`calibrate.py` готує дані; він не оцінює коефіцієнти QPM. Готовий `QPM_ready.xlsx` є статичним знімком і після перерахунку CSV автоматично не оновлюється.

## Excel

`tools/build_dataset_workbook.mjs` зберігає код створення справжнього XLSX. Це необов'язковий інструмент для середовища з `@oai/artifact-tool` (Codex); ця бібліотека не входить до Python requirements і не потрібна партнеру для запуску моделей.

Вхід builder — `data/documentation/workbook_data.json`, який створює `calibrate.py`. Після створення книги перевірку чисел виконує `tools/verify_dataset_workbook.py`; для неї теж потрібний цей JSON. Візуальну перевірку вигляду аркушів треба виконати окремо.

Значення CSV і Excel порівнювалися при первинній підготовці; історичний протокол є в `data/documentation/delivery_checks.json`.

## Обмеження чесної історичної перевірки

- Сезонність оцінюється заново на кожному навчальному зрізі.
- Поточний квартальний ВВП прихований; припускається затримка на квартал.
- Однак джерельні значення містять пізніші перегляди, а точний календар усіх минулих публікацій не відновлено.
- QPM має фіксовану калібровку навчального шаблону 2026 року, застосовану ретроспективно.
- Тому результат названо псевдопозавибірковим тестом. Повний real-time backtest потребує архівних вінтажів.
