# Розширення даних для рішення монетарної політики

Інформаційний зріз: **22.10.2026**. Останній повний місяць — вересень 2026. Відтворювана побудова: `tools/build_policy_dataset.py`. Підготовлені таблиці: `data/policy/2026-10-22/`. Старі `data/raw/`, `data/inputs/`, `data/model/` та `sources/` не редагувалися.

## Що справді додано

Інвентаризацію попередніх файлів, контрольні суми й перелік наявних показників збережено **до** створення розширення у `inventory_before.json`. Розширення містить 8 506 спостережень 33 рядів, 309 місячних періодів і 103 квартали:

- **994 значення нових офіційно завантажених історичних рядів:** валові резерви — 285 місяців, 2003-01–2026-09; чисті резерви — 178 місяців, 2011-12–2026-09; купівля, продаж і сальдо інтервенцій — по 177 місяців, 2012-01–2026-09.
- **6 552 значення вперше витягнуто з уже наявного `CPI_m.xlsx`:** 12 національних товарних груп, зміна м/м від 2001-01 і р/р від 2007-01 до 2026-09. Це нова підготовлена деталізація нашого файлу, а не нове завантаження.
- **960 значень загальної та базової інфляції явно повторно використано** з попереднього `observations_long.csv` для перевірок та зручного приєднання. Ці рядки не враховуються як приріст.

Один попередній вересневий snapshot резервів уже був у політичних доказах попереднього дослідження. Приріст цього запуску — довга зіставна історія, а не нібито вперше знайдений вересневий факт.

## Першоджерела й часові визначення

### Резерви

Джерело — [офіційний графік НБУ](https://bank.gov.ua/ua/markets/international-reserves-allinfo/dynamics) та його JSON-маршрут `/ua/tables/int-reserves-dynamics?startDate=01.01.2000&endDate=01.10.2026`.

API повертає `date`, `on_date`, `RES_OffReserveAssets`, а за доступні роки — `IRAM_NetReserves`. Відповідність перевіряється для кожного рядка: `date=01.09.2026`, `on_date=01.10.2026` означає **запас на кінець вересня**, а не на початок вересня. Вихідні одиниці — млрд дол. США в еквіваленті; підготовлені — **млн USD**, множення на 1 000. Валові й чисті резерви зберігаються окремо.

На дату завантаження офіційна таблиця дає за вересень **47 110,43 млн USD валових** і **32 572,56 млн USD чистих** резервів. Це відрізняється від **47 101,8 млн USD попередніх** у [пресрелізі 07.10.2026](https://bank.gov.ua/ua/news/all/mijnarodni-rezervi-stanovili-471-mlrd-dol-ssha-za-pidsumkami-veresnya). Обидва значення мають різний вінтаж; попередній факт не переписано й не використано як одночасно незалежне спостереження.

НБУ описує строки поширення: попередні дані не пізніше 7-го числа наступного місяця, уточнені — не пізніше 21-го. **Строк не прирівняно до фактичної дати релізу конкретного історичного значення.** `published_at=unknown`, якщо точна дата саме цього запису не підтверджена. Дата завантаження та HTTP Last-Modified також не є датами первинної публікації.

### Інтервенції

Джерело — [офіційна сторінка інтервенцій НБУ](https://bank.gov.ua/ua/markets/currency-interventions) та її JSON-маршрут `/ua/tables/currency-interventions` із річними вікнами. Великі багаторічні запити не дали придатного результату; річні вікна дали повну історію. URL кожної відповіді записано у маніфесті та довгій таблиці.

**Дата обліку — дата укладання угоди.** Це прямо зазначено на сторінці НБУ. Місячні інтервенції не реконструйовано з тижневих сум: тижні, що перетинають межу місяця, не дозволяють точного такого перетворення. Офіційний тижневий `InterventionsResults.xlsx` збережений лише як додатковий матеріал, не доданий повторно до місячної матриці.

В API `VolumNbuICM_BuyPerM` — купівля; `VolumNbuICM_SelPerM` — продаж із від'ємним знаком; `VolumNbuICM_BalPerM` — купівля мінус продаж. Перетворення у підготовленій таблиці:

- `fx_purchases_usd_mn`: додатна купівля, API × 1 000;
- `fx_sales_usd_mn`: додатний продаж, API × −1 000;
- `fx_net_purchases_usd_mn`: купівля мінус додатний продаж, API × 1 000. Від'ємне значення означає чистий продаж.

Вересень 2026: купівля 0; продаж 5 518,99; сальдо −5 518,99 млн USD. **Балансові продажі 5 449,9 млн USD із пресрелізу про резерви — інша дата обліку**, їх не змішано з угодами. Зміна резервів включає також надходження, виплати, переоцінку й інші операції; вона не дорівнює самому сальдо інтервенцій.

Річний API може показувати попередній грудень на початку відповіді. Для періоду використовуються самі `date`/`exp_date`, а не назва річного файла. Код перевіряє унікальність `(series,period)`; точні дублікати порівнюються, не додаються. Незгода дублікатів є помилкою.

### Компоненти CPI

Джерело — збережений [файл НБУ / Держстату](https://bank.gov.ua/files/macro/CPI_m.xlsx): аркуш `1` (р/р), аркуш `2` (м/м), рядки **4–15**, дати рядка 2. Витягнуто лише 12 національних груп; регіональні рядки не змішуються з ними. Для кожного значення збережено точну клітинку та хеш книги.

Показники вже є **змінами у відсотках**, 100 не віднімається. Це NSA. Ціни груп — **не внески у CPI**. Без перевірених ваг їх не можна складати у внески або віднімати від загального CPI як готову декомпозицію. Територіальні обмеження та зміни охоплення з приміток початкової книги зберігають силу.

## Файли та API для модельного запуску

- `monthly.csv`: широкий CSV, `period=YYYY-MM`; порожнє поле означає відсутність факту, а не нуль.
- `long.csv`: значення плюс `series`, `period`, `units`, `status`, `published_at`, `published_at_status`, `source_url`, `raw_file`, `raw_sha256`, `locator`, `retrieved_at`, `information_cutoff`, `date_basis`, `vintage`, `increment`.
- `quarterly.csv`: широкий CSV з `period=YYYYQn`.
- `quarterly_long.csv`: квартальний результат, правило агрегування, три вихідні місяці, одиниці та хеші.
- `series_dictionary.csv`: визначення показників і правила агрегування.
- `coverage.csv`: початок/кінець, кількість фактів, тип приросту.
- `downloads_manifest.json`: URL, HTTP-статус, розмір і SHA-256 кожного прийнятого нового файла; збережені CPI-книги позначені як існуючі.
- `checks.json`: результати фактично виконаних перевірок і ключові останні значення.

Головні валютні колонки: `gross_reserves_usd_mn`, `net_reserves_usd_mn`, `fx_purchases_usd_mn`, `fx_sales_usd_mn`, `fx_net_purchases_usd_mn`. CPI-якорі: `cpi_headline_mom`, `cpi_headline_yoy`, `cpi_core_mom`, `cpi_core_yoy`. Компоненти: `cpi_<group>_mom/yoy`; точний перелік є у словнику.

## Агрегування

Квартал створюється **лише за наявності всіх трьох місяців** відповідного ряду; перенесення й інтерполяції немає.

- Резерви: запас останнього місяця кварталу, не сума і не середнє.
- Інтервенції: сума трьох потоків, млн USD за квартал.
- Зміни цін м/м: `100 × (добуток(1 + m/100) − 1)`, отже в квартальному файлі це **% кв/кв NSA**.
- Зміни цін р/р: останній місяць кварталу, **не** інфляція середнього квартального індексу р/р. Для останньої слід будувати рівні та порівнювати квартальні середні окремо.

Квартальні колонки зберігають назву місячного ряду для зручності, але їхні одиниці/операція можуть змінитися. Для моделювання слід читати `quarterly_long.csv` і словник, а не вгадувати правило за суфіксом.

## Часова доступність і допустиме використання

Це **поточний історичний snapshot на 22.10.2026**, а не база справжніх історичних релізів. Окремі старі значення могли переглядатися. `status=observed` означає опубліковану статистику в цьому snapshot, а не гарантію знання того самого числа в минулому.

Для прогнозного тесту зі зрізом на кінець місяця мінімально обережний технічний варіант — використовувати нові місячні сигнали з **лагом два місяці**. Це явно **наше припущення доступності**, не відновлений календар релізів. Навіть такий лаг не усуває revision leakage поточного історичного snapshot; строгий real-time тест потребує фактичних вінтажів. Для поточного рішення 22.10 вересневі дані використовуються як уже доступні.

Можливий діагностичний індикатор тиску — чистий продаж за угодами / валові резерви попереднього місяця. Він не є оціненим причинним шоком чи самостійним критерієм ставки. Однаковий обсяг інтервенцій залежить від курсового режиму, допомоги, імпорту й очікувань. Нові ряди можна перевірити в сателітах та валютних ризиках; **довільні коефіцієнти в QPM не додано**.

## Виконані перевірки та обмеження приросту

Перевірено: унікальність ключів; відсутність майбутніх періодів після 2026-09; скінченність чисел; відповідність дат запасу; купівля − продаж = сальдо; валові резерви не нижчі чистих; останні CPI-якорі; повноту кварталів; незмінність вихідних файлів через збережені контрольні суми.

В офіційному FX API за вересень 2014 різниця між опублікованим сальдо й різницею опублікованих компонентів становить близько **1 USD** через округлення; допуск перевірки — **10 USD = 0,00001 млн USD**. Офіційні значення не переписано задля нульового залишку.

**Не додано:** довгий зіставний ряд зовнішніх надходжень/виплат та структурного фіскального імпульсу. Їх не можна вирахувати залишком із резервів або підмінити валовими надходженнями Мінфіну. Разовий уже відомий пресреліз не оголошено новою довгою історією. Цей етап свідомо дає мінімальний надійний приріст двох блоків, придатний для реального запуску без неперевірених регресорів.

## Відтворення

Запустити `build_policy_dataset.py` у bundled Python з установленим `openpyxl` для **читання** джерел; типовий режим offline й використовує збережені raw. Опція `--download` завантажує лише відсутні прийняті офіційні файли. Код пише лише у новий каталог `data/policy/2026-10-22/` та не змінює стару матрицю. Перевірка виходить з помилкою за конфліктних дублікатів, порушення арифметики понад допуск або порушення зрізу.
